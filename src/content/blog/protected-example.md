# 🎉 비밀글 열람에 성공했습니다!

이 내용은 비밀번호(`test1234`)를 올바르게 입력하고 복호화되었을 때만 표시되는 본문입니다.

## 보안 작동 방식

1. 정적 빌드 시 본문 HTML이 **AES-256-GCM** 방식으로 강력하게 암호화됩니다.
2. 배포된 HTML 소스 코드나 개발자 도구(`F12`)를 열어보아도 원문 텍스트는 전혀 노출되지 않습니다.
3. 방문자가 비밀번호를 입력하면 브라우저 메모리 내에서 실시간으로 복호화되어 화면에 렌더링됩니다.
4. **쿠키 기억하기**를 켜두면 지정된 기간 동안 브라우저에 쿠키가 저장되어 재방문 시 비밀번호 입력 없이 바로 열람할 수 있습니다.
